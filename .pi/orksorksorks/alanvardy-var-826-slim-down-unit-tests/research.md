## Cross-Cutting Observations
- **The mirror is seam-driven, not content-driven**: iOS and watch unit suites test the same persisted contracts through different seams (`InMemoryEventStore`/`--seed` + key prefix `test-*` on iOS; sharedWatchEventStore + `wtest-*` on watch), and the seam difference is the *only* difference in the near-duplicate test bodies (Q1 pair 2 copies, Q2 restatement verdict, Q4 fake-session pair).
- **Duplication concentrates in the sync layer**: the "receive → persist → hook / absent key no-op" trio was written once and re-typed ~8 times (Q2 §3.1), and the two largest suites (SkippedReminderSyncServiceTests.swift 660, WatchSyncPipelineTests.swift 576) are each other's biggest mirror (Q1 pair 2 ≈15% verbatim).
- **Per-file fixture culture**: every fixture (makeReminder, sharedWatchEventStore, fake sessions, transcribers, fetchers) is file-private by convention; the code comments name the cause explicitly ("private to its own source file, so it is not reusable here" — ActionButtonTests:99-100; "cannot be imported across test bundles" — WatchSyncPipelineTests:7). A shared fixture library does not exist.
- **Serialization is near-total**: all 27 suites are `.serialized`; the dominant reasons are real UserDefaults/App Group keys (both suites of the store pair write the same keys) and MainActor timing tests. Watch suites serialize *defensively* (ReminderStoreWatchTests 21-24) even when UUID keys already isolate.
- **Test machinery is structurally part of production**: SingleThreadCore ships InMemoryEventStore + UITestingSeed + 24-key reset into every artifact; activation is purely launch-arg-driven, with the iOS `--ui-testing` store branch the only `#if os(iOS)` gate. The `UITestingSeedTests` suite (16 tests) covers the harness itself.
- **Counting tools measure volume, not value**: count_tests.sh is mechanically accurate (all numbers reproduce) but its comments and two patterns are stale/dead; per-test assertions counts (expect/require) are the only "value" proxy used historically (var-755's 60.5% single-assertion heuristic).
- **Prior tickets set the precedent**: deletions happened only where a lower layer proved the behavior (var-796 criterion) or tests were byte-identical cross-target (var-755 design.md:48); the result was a 552→398 unit reduction plus a 52→23 UI cut and 23+15 UI-method deletions — yet the pair-2 near-verbatim copies, the dead `SingleThreadUITestCase`, and 9 identical `makeReminder` copies all still exist.
