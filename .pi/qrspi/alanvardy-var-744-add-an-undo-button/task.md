# Task — Add an undo button (VAR-744)

When a reminder is completed, the app saves that reminder's identifier so the
completion can be undone. An undo button appears in the top-left corner of the
iOS main screen; tapping it reverts the most recent completion. A toggle in
the interface settings menu lets the user hide the undo button.
