# Task — Reminders not having the correct priority

Some reminders, intermittently, display with no priority on both the iPhone
app and the Apple Watch app even though the same reminder has a priority (e.g.
high) set in Apple Reminders. The user suspects it may be related to the
reminder having been skipped once via the app's skip gesture.

Find the root cause of this inconsistent priority display and fix it so that a
reminder's priority is always shown correctly on both platforms. The fix ships
with unit and UI test coverage per project conventions.
