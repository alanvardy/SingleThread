# Task

VAR-781: Sort reminders by list.

After reminders are sorted by their user-selected primary option (priority, due date, or title), apply the reminder's list (calendar) as a secondary sort so reminders from the same list stay grouped together. The list tie-break must apply consistently across all surfaces that render the sorted reminder array — iOS, watchOS, macOS, and the widget — and must be covered by unit and UI tests.
