# Task — Create a guide (VAR-649)

The watchOS companion app needs a one-time onboarding overlay. When the user
first enters the watch app, the main view is covered by a guide overlay that
shows "swipe right to complete" and "swipe left to skip", with an arrow
pointing at the settings entry point. The guide should appear only once, and a
button in the settings menu should let the user show the guide again on demand.
