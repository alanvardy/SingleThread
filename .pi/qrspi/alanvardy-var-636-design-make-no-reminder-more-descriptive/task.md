# Task

Make the "No Reminders" empty state in the iOS app more descriptive. When the
store has no reminders to show, the app currently displays a terse
`ContentUnavailableView` with the title "No Reminders" and the description
"You don't have any reminders yet." This task makes that empty state more
informative and helpful, so a user landing on it understands the current state
and what they can do next.
