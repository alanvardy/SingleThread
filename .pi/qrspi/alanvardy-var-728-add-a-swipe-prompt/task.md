# Task

On the iOS app's single-reminder screen, the reminder card should show a
swipe-instruction prompt — "← Swipe left to skip | Swipe right to complete →"
— placed below all of the card's content, with a "Dismiss" button beneath it.
The prompt is enabled by default; tapping Dismiss disables it; and a toggle in
the Interface section of Settings turns it on and off. This is iOS-only work;
the watch app is out of scope.
