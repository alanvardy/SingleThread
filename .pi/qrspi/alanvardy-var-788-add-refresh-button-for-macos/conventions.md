## Build/verify gotchas
- **One xcodebuild test process at a time** (AGENTS.md:19): simulator contention; CI encodes `-parallel-testing-enabled NO` + `-maximum-concurrent-test-simulator-destinations 1` on every test step (`ci.yml:76-77,145-146,204-205,265-266`) with clone-connection/EKReminder-SIGTRAP comments. On `Busy`/`RequestDenied` runner failures: `xcrun simctl shutdown all`, kill orphan `xcodebuild`/`xctest`.
- **Destination pinning**: name-only `iPhone 17` is ambiguous with multiple runtimes — use `,OS=<ver>` or `,id=<UDID>` (`scripts/test.sh:25-44` resolves + pre-boots; AGENTS.md:15-17). macOS destination is the unpinned `platform=macOS` everywhere (`Makefile:8`, `scripts/test.sh:12`, `ci.yml:297,308`).
- **Warnings are errors** project-wide (`SWIFT_TREAT_WARNINGS_AS_ERRORS = YES` Debug+Release); SwiftLint `--strict`. Set target overrides in pbxproj, never CLI flags (conflicts with SPM `-suppress-warnings`).
- **Concurrency**: app+watch targets default `@MainActor` (`SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`); `SingleThreadCore` package, widget, tests do NOT — annotate explicitly. Swift 6 mode.
- **Persistence**: every watch-shared value (incl. `--ui-testing`/`--seed` seams) round-trips through `AppGroup.defaults` (suite `group.app.alanvardy.SingleThread`), never `UserDefaults.standard` (`AppGroup.swift:8`; `UITestingSeed.swift:62-98`).
- **Debug builds only** for fast iteration (`DEBUG_INFORMATION_FORMAT = dwarf`); release = `dwarf-with-dsym`.
- **SwiftFormat pitfalls**: unit-test names stripped if prefixed `test`/`testing` (phantom reverts); `trailingClosures` formatting disabled but SwiftLint `trailing_closure` opt-in enabled (tools disagree).
- **`.accessibilityIdentifier` vs visible text**: UI tests match identifiers (`app.buttons["completeButton"]`) preferentially, but some tests match localized visible text (`app.buttons["Skip"]`, `["Refresh"]`) — changing visible copy can break those.
- **Accessibility audit strictness**: local runs extra `.hitRegion`/`.dynamicType` beyond CI — a local hit-region failure can be local-only (AGENTS.md:167-172). Caption-sized buttons need `.padding` on the label; `.frame(minHeight: 44)` does not expand the a11y label frame.
- **File-length/type-body limits** (`.swiftlint.yml:29-35`): `ContentView.swift` is near the 650-line warning threshold; extensions (`ContentView+iOS.swift` etc.) exist to split `type_body_length` — new macOS UI code placement must mind this.
- **StoreKit**: premium id = `EntitlementStore.unlockProductID` (single source of truth); sandbox tester + Paid Applications Agreement needed for real-device; see the `storekit` skill.
- **Testing gate**: new features ship with unit + UI tests; bug fixes add a reproducing test first; full `./scripts/test.sh` runs once per PR by the parent after phases commit (not per worker).
