# Conventions — SingleThread (shared factual appendix)

Dense reference for Structure/Plan. Facts verified against the current working tree; line refs to `Makefile`, `scripts/`, `.github/workflows/ci.yml`, and the `*Tests.swift` set. Do not re-read the source tree for these facts.

## Canonical commands

- **Full CI-equivalent gate** (formats, lints, builds, Periphery, unit + UI tests, incl. macOS unit step): `./scripts/test.sh`. All checks pass ⇒ `echo "✅ All CI checks passed."` (`scripts/test.sh:296`). macOS unit step runs `xcodebuild -scheme SingleThread -destination "$MAC_SIM" -configuration Debug ... CODE_SIGNING_ALLOWED=NO test -only-testing:SingleThreadTests` (`scripts/test.sh:286-292`) where `MAC_SIM="platform=macOS"` (`:12`).
- **Make targets** (`Makefile:15` .PHONY list): `make build` / `make test` / `make ui-test` / `make watch-test` / `make watch-ui-test` / `make mac-build` (`:23-24`) / `make mac-test` (`:26-27`, same `-only-testing:SingleThreadTests`) / `make mac-run` (`:29-30`) / `make mac-distribute` (`:40` → `scripts/distribute-macos.sh`) / `make periphery` / `make lint` / `make format` / `make coverage*` / `make simverify`. `MAC_SIM := platform=macOS` (`:8`). **No `mac-ui-test` target exists.**
- **CI jobs** (`.github/workflows/ci.yml`): iOS simulator matrix `iPhone 17` / `iPad (A16)` with `-parallel-testing-enabled NO` / `-maximum-concurrent-test-simulator-destinations 1` (`:68-73`, `:136`, `:256`); UI classes split across 3 disjoint jobs via `UI_GROUP_A/B/C_ONLY_TESTING` (`:15-21`); `mac-tests` job (`:270`) = Build macOS (`:293-303`) + Unit tests macOS `-only-testing:SingleThreadTests` (`:304-315`), uploads `mac-unit-test-results` on failure; watch-ui job creates fresh standalone watch simulator "CI Watch S11" (`:393`+). **No macOS UI-test job anywhere.**
- **Destination pinning**: name-only `iPhone 17` is ambiguous with multiple runtimes — pin `,OS=<ver>` or `,id=<UDID>`; scripts accept `SIM=`. One xcodebuild test process at a time; on Busy/RequestDenied: `xcrun simctl shutdown all`, kill orphaned `xcodebuild`/`xctest`. Watch UI tests need paired sim (`xcrun simctl pair <watchUDID> <phoneUDID>`).
- **Lint/format**: `make format` = SwiftFormat (`.swiftformat`: `organizeDeclarations`, `preferSwiftTesting`, `blankLinesAroundMark`; disables `trailingCommas`, `trailingClosures`, `isEmpty`; UI tests excluded) then `make lint` = SwiftLint `--strict` (every warning an error; config `.swiftlint.yml` incl. 35 opt-in rules). `make periphery` = `periphery scan --strict`.
- **Targeted suites**: `xcodebuild -only-testing:SingleThreadTests` (Swift Testing) / `-only-testing:SingleThreadUITests` (XCTest, a11y audit) with destination pinned per above.

## Build/verify gotchas

- Debug builds set `DEBUG_INFORMATION_FORMAT = dwarf` (fast); release switches to `dwarf-with-dsym`.
- `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor` on iOS + watch app targets — async funcs default to MainActor there; **do not wrap in `Task { @MainActor in }`** (redundant). `SingleThreadCore`, widget, and test targets do NOT enable it — annotate explicitly.
- `SWIFT_TREAT_WARNINGS_AS_ERRORS = YES` project-wide; scope per-target overrides in the pbxproj, never via CLI flags (conflicts with the SPM package's `-suppress-warnings`).
- macOS destination `platform=macOS` with `CODE_SIGNING_ALLOWED=NO` is the only macOS build/test shape used (Makefile `:23-27`, scripts/test.sh `:286-292`, CI `:293-315`).
- New `.swift` files are auto-discovered (synchronized groups, `objectVersion = 77`) — no pbxproj edit; new **test targets** require pbxproj IDs, scheme wiring, `-only-testing` entries in `scripts/test.sh`, and CI matrix entries.
- Launch-arg seams (`--seed`, `--ui-testing*`) must be stored through `AppGroup.defaults` (suite always exists on simulator; `.standard` diverges silently).
- New unit suites must be added to `Makefile` `test` target and `scripts/test.sh` if they need explicit `-only-testing` filters.
- SwiftLint `identifier_name` ≥ 3 chars (exceptions `id`, `e`, `d`, `rt`, `to`, `gvm`).
- A test failure untouched by your diff is likely pre-existing on `origin/main` — check `git blame`/CI history before debugging; fix in a separate scoped commit.
